First issue · 15 October 2026

Two GitHub changes worth checking

GITHUB APPS

Create repositories with less access.

GitHub announced a separate repository_creation:write permission on October 13. Apps that create repositories can request a narrower permission than general repository administration. An organization administrator still needs to install the app.

Our check: If your integration asks for administration only to create repositories, review the new scope. Keep permissions your other operations need and check the Enterprise Server availability notes.

Original GitHub changelog ↗
COPILOT POLICY

Require a fresh policy check.

GitHub announced forceRemoteSettingsRefresh on October 13. Supported Copilot clients can refuse to continue when they cannot confirm current enterprise policy.

A server-delivered setting applies on subsequent startups after the client receives it. Device management or file-delivered settings can apply from first startup.

Our check: Include policy-service outages in rollout testing. Client support and first-start behavior matter.
